# Technical toolkit marks

These local assets identify technologies already listed in the portfolio. Logos remain the property of their respective owners and do not imply endorsement.

- Python, PHP, JavaScript, TypeScript, Next.js, HTML5, CSS3, CodeIgniter, MySQL, Git, and Linux: original-color SVGs from [Devicon v2.16.0](https://github.com/devicons/devicon/tree/v2.16.0/icons), except CodeIgniter uses its plain brand-color variant. See `DEVICON-LICENSE.txt`.
- Cuckoo3: [documentation mark in the official Cuckoo3 repository](https://github.com/cert-ee/cuckoo3/blob/main/docs/src/assets/images/cuckoo3-docs-round.png).
- XGBoost: [logo from the official project website](https://xgboost.ai/images/logo/xgboost-logo-trimmed.png).

SQL, Computer Networking, Cybersecurity, Malware Analysis, DevSecOps, Machine Learning, and Data Preparation use representative icons from the existing Phosphor package, not official brand logos.

The displayed names, groups, and order are unchanged. Icons are decorative because each row retains its readable technology name.
