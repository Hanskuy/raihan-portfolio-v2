# Home Page Direction

This page intentionally overrides the generated FAQ/OLED recommendation, which did not fit the recruiter-oriented portfolio brief.

## Mode

Persuade. A recruiter should understand identity, evidence, role fit, and next action within 30 seconds.

## Design Read

Editorial-technical developer portfolio with a calm, precise tone. Verified experience and work evidence lead; interface decoration recedes.

## Dials

- Design variance: 6/10
- Motion intensity: 3/10
- Visual density: 4/10

## Visual System

- Warm-neutral light surfaces and cool charcoal dark surfaces.
- A single restrained cobalt accent for links, focus, and primary actions.
- Geist Sans for display and body, Geist Mono for metadata and technical detail.
- Soft 14px radii for media and grouped surfaces; pill radius only for compact buttons.
- Editorial asymmetry in the hero and selected work. Strict single-column collapse under 768px.
- Borders and whitespace communicate hierarchy; shadows are rare.

## First Viewport

Left-weighted identity and role statement, concise location line, two distinct actions, and Raihan's supplied profile photograph. No fake terminal, badges, trust strip, or decorative scroll cue.

## Signature Interaction

The theme control rotates through system, light, and dark with an immediate label update. All other motion is limited to focus, hover, menu, and form-state feedback.

## Anti-Patterns

No neon green, hacker motifs, fake code windows, identical three-card grids, decorative metrics, skill progress bars, or excessive motion.
